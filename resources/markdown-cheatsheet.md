# Markdown Cheat Sheet

Markdown is a simple language used to format text on GitHub.

README files are written using Markdown.

---

# Headers

Use `#` symbols to create headings.

Markdown:

```markdown
# Header 1
## Header 2
### Header 3
#### Header 4
```

Example:

# Header 1

## Header 2

### Header 3

#### Header 4

---

# Bold Text

Markdown:

```markdown
**Bold Text**
```

Result:

**Bold Text**

---

# Italic Text

Markdown:

```markdown
*Italic Text*
```

Result:

*Italic Text*

---

# Bold and Italic

Markdown:

```markdown
***Bold and Italic Text***
```

Result:

***Bold and Italic Text***

---

# Bulleted Lists

Markdown:

```markdown
- Item One
- Item Two
- Item Three
```

Result:

- Item One
- Item Two
- Item Three

---

# Numbered Lists

Markdown:

```markdown
1. First
2. Second
3. Third
```

Result:

1. First
2. Second
3. Third

---

# Checklists

Markdown:

```markdown
- [x] Install Git
- [x] Install VS Code
- [ ] Complete Lab 1
```

Result:

- [x] Install Git
- [x] Install VS Code  
- [ ] Complete Lab 1

---

# Links

Markdown:

```markdown
[GitHub](https://github.com)
```

Result:

[GitHub](https://github.com)
